### From 2 AM Failure to 8 AM Fix: Self-Healing Docs, Agent Instructions Included

**LavaCon 2026**

What happens between a product change breaking the docs at 2 AM and a reviewed fix waiting at 8 AM. This talk walks through a five-step self-healing loop, a maturity ladder for deciding how much autonomy each content area gets, and the metrics that say when to take autonomy back. It also treats the instructions we give AI agents, like AGENTS.md files and skill libraries, as a doc set that drifts and can be tested.

**Topics covered:**

- The detect, diagnose, repair, verify, and report loop
- A five-level maturity ladder and the test coverage each level needs
- Agent instructions as testable documentation
- Healing and instruction-library metrics, and demotion
- A basic loop you can build in about a day
